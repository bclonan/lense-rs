# Demo script

Windows setup is paused while the Norton IDP.Generic report is reviewed. For a demo now, open Control, choose Woodcutting lab, and select Run this task. The native procedure below is for an approved future release. Do not restore or run a quarantined copy.

1. Open the hosted Lense website. Explain that tasks and replay live in an ordinary web app.
2. Download and run the portable bridge. Pair the desktop, approving the browser connection permission and native Windows prompt when shown.
3. Open the standalone Woodcutting Lab in another visible window. It has mouse interaction and no WebMCP tools.
4. Select its window in Lense. Choose Woodcutting Lab autopilot.
5. Enter "Go chop wood for ten minutes. If chopping stops, find another tree and continue." Choose the duration and verification interval in the adjacent controls.
6. Run the task. Point out the identified tree box, click marker, and verification result.
7. Keep the lab visible. Its current tree depletes after a few seconds. The native watch detects a change, the evaluator sees IDLE, and the next action selects a tree.
8. Return to Lense and inspect recovery events. Step through captured frames and export JSONL.
9. Press STOP CONTROL. The native session is revoked. Re-pair before sending further desktop input.

The browser-only lab is a convenient first demonstration. Label it as such. Show the native-window version to demonstrate actual Windows input.

## Other software

In a new Notepad document, select the Notepad window, observe, click the editor, type "Hello from Lense", and send Ctrl+S. Observe the Save As dialog. Choose a save destination yourself.

In a blank Paint canvas, select a drawing tool and send a normalized drag. Compare before and after screenshots. Lense uses Windows pointer input, not a Paint API.

For a legacy app, ask the external WebMCP agent to identify a visible button, click it, then verify the dialog in a new screenshot. Stop if the visual result is uncertain.

Use `/input-lab` when you want disposable equivalents without creating or saving documents.
