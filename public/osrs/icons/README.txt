Lense OSRS reference symbols

These SVG files are original Lense artwork drawn for navigation in the reference
library. They are generic symbols, not screenshots, OSRS inventory sprites, or
pixel-matching templates. Different game items can share one symbol.

Do not use a symbol to conclude that an object is present in a screenshot.
Use current observations, visible labels, and user-saved screenshot examples.

The manifest is src/osrs/assets.ts. Its OSRS Wiki links explain each concept;
they are not the sources of the artwork. No OSRS Wiki images or game art were
downloaded for this symbol set.
